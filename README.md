## 安装

**Mac 应用：** 双击打开下载的 DMG，把 Poqo 拖进右侧「应用程序」，复制完成后打开。以后点击应用左下角的蓝色按钮更新。

<details>
<summary>浏览器扩展怎么安装？</summary>

1. 解压 ZIP，将 `Poqo-Collector` 文件夹保存在固定位置。
2. Chrome 地址栏输入 `chrome://extensions`，Edge 输入 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择该文件夹。
4. 打开 Poqo，扩展会自动发现应用；首次使用时，在 Poqo 中点击「允许连接」。
5. 刷新网页，保持 Poqo 运行，即可开始收藏。

更新扩展时，将新版内容替换到原文件夹，再点击浏览器扩展页的「重新加载」。安装后不要删除该文件夹。

</details>

<details>
<summary>首次打开被 macOS 阻止怎么办？</summary>

内测版尚未经过 Apple 公证。确认下载来源后，在「系统设置 → 隐私与安全性」中找到 Poqo，点击「仍要打开」。

</details>
