## 安装

**Mac 应用：** 双击打开下载的 DMG，把 Poqo 拖进右侧「应用程序」，复制完成后打开。开启「自动检查更新」后，每次启动立即检查，运行期间默认每小时检查。发现新版本时，应用左下角会显示蓝色更新按钮；关闭更新窗口后仍可点击按钮继续更新。安装 0.7.5 后，可通过「Poqo → 检查更新…」获取后续版本。

<details>
<summary>浏览器扩展怎么安装？</summary>

**推荐：** 在 Poqo 中打开「设置 → 浏览器采集 → 安装…」，按三步指引完成安装。应用会自动准备好固定位置的扩展文件。

也可以手动下载并安装：

1. 解压 ZIP，将 `Poqo-Collector` 文件夹保存在固定位置。
2. Chrome 地址栏输入 `chrome://extensions`，Edge 输入 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择该文件夹。
4. 打开 Poqo，扩展会自动发现应用；首次使用时，在 Poqo 中点击「允许连接」。
5. 刷新网页，保持 Poqo 运行，即可开始收藏。

通过应用内指引安装的扩展：更新 Poqo 后，再打开「安装…」准备新版文件，然后到浏览器扩展页点击「重新加载」。手动下载的扩展：将新版内容替换到原文件夹，再点击「重新加载」。安装后不要删除或移动该文件夹。

</details>
